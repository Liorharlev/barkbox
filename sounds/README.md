# sounds/

Put bark clips here as `.mp3` or `.wav` files. Short single events work best
(one bark, a short burst, a growl-into-bark). The scheduler strings several
together to build an "episode".

Start with a handful of unlabelled clips — the system will use them for every
behavior. As the library grows, label clips per behavior in `tags.yaml`.

Suggested naming: `bark_01.mp3`, `bark_02.mp3`, … (arbitrary — only `tags.yaml`
keys need to match the filenames exactly).
